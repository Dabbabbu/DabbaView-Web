DabbaView 개인정보처리방침

마지막 업데이트: 2026-09-23 · 적용 대상: DabbaView Web (https://dabbabbu.github.io/DabbaView-Web/) 및 같은 웹앱을 담은 안드로이드 앱 DabbaView

한 줄 요약

DabbaView는 의료 영상을 서버로 보내지 않습니다. 영상은 사용자의 기기(브라우저) 안에서만 열리고 처리되며, 개발자는 사용자의 영상·환자 정보·사용 기록을 수집하거나 볼 수 없습니다.

1. 수집하지 않는 것

  • DICOM 등 의료 영상 파일과 그 안의 환자 정보 — 기기 밖으로 전송되지 않습니다.
  • 이름·이메일·전화번호 등 개인 식별 정보 — 앱은 회원 가입이 없습니다.
  • 사용 기록·분석(Analytics)·광고 식별자 — 분석 도구나 광고 SDK를 넣지 않았습니다.

2. 기기 안에만 저장되는 것

  • 설정(화면 구성·도구·레이아웃 등): 브라우저 저장소(localStorage)에 저장됩니다.
  • 클라우드에서 받은 파일 캐시: Google Drive·OneDrive에서 불러온 파일을 다시 받지 않도록 브라우저 저장소(IndexedDB)에 보관합니다. 앱의 설정 ▸ 캐시에서 언제든 지울 수 있고, 브라우저 데이터 삭제로도 지워집니다.
  • 앱 파일 캐시(서비스 워커): 인터넷 없이도 앱이 열리도록 화면·프로그램 파일만 저장합니다. 의료 영상은 이 캐시에 저장하지 않습니다.

이 저장소는 사용자의 기기에만 있으며 개발자에게 전송되지 않습니다.

3. 외부와 통신하는 경우

다음은 사용자가 그 기능을 직접 쓸 때만 일어납니다.

  • Google Drive 연동: 사용자가 로그인하고 고른 파일만 기기로 내려받습니다. 통신 상대는 Google(accounts.google.com, googleapis.com)이며, 이용에는 Google의 개인정보처리방침이 함께 적용됩니다.
  • OneDrive 연동: 위와 같으며 통신 상대는 Microsoft(login.microsoftonline.com, graph.microsoft.com)입니다.
  • 새 버전 확인: 앱을 열 때 배포 서버의 버전 파일과 GitHub의 공개 릴리스 정보(api.github.com)를 읽습니다. 개인 정보는 보내지 않습니다.
  • 웹사이트 호스팅: 앱 파일은 GitHub Pages에서 제공되며, 접속 시 GitHub가 통신에 필요한 접속 기록(IP 주소 등)을 자체 정책에 따라 처리할 수 있습니다.

클라우드 로그인 정보(토큰)는 해당 서비스의 로그인 절차에 따라 기기 안에 보관되며, 개발자 서버로 전송되지 않습니다. 개발자는 사용자의 클라우드 파일에 접근할 수 없습니다.

4. 권한

안드로이드 앱은 인터넷 접속 권한만 사용합니다. 사진·파일 접근은 사용자가 파일을 고를 때 시스템 선택 창을 통해서만 이루어지며, 앱이 기기의 파일을 스스로 뒤지지 않습니다.

5. 어린이

이 앱은 의료 영상을 보기 위한 도구로, 만 13세 미만 어린이를 대상으로 하지 않으며 어린이의 개인정보를 의도적으로 수집하지 않습니다.

6. 의료기기 아님

DabbaView는 연구·교육·개인 참고용 소프트웨어이며 진단용 의료기기가 아닙니다. 임상 판단에 사용하지 마십시오.

7. 문의

Privacy Policy (English)

Last updated: 2026-09-23 · Applies to DabbaView Web and the DabbaView Android app.

Summary

DabbaView does not upload your medical images. Files are opened and processed entirely on your device. The developer cannot see your images, patient data, or usage.

Not collected

No medical images or patient data leave your device. No accounts, no analytics, no advertising identifiers.

Stored on your device only

App settings (localStorage), an optional cache of files you downloaded from cloud storage (IndexedDB, clearable in Settings ▸ Cache), and the app's own program files (service worker cache). Medical images are never written to the service worker cache.

Network access

Only when you use those features: Google Drive and OneDrive sign-in and file download (subject to Google's and Microsoft's own privacy policies), and an update check against the deployment's version file and the public GitHub releases API. The site is hosted on GitHub Pages, which may log connection data under its own policy.

Permissions

The Android app uses internet access only. File access happens through the system file picker when you choose files.

Not a medical device

DabbaView is for research, education, and personal reference. It is not a diagnostic medical device.

Contact

GitHub Issues — please do not post patient data.
